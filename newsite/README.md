# AH Traders - Corporate Website

Official corporate website for AH Traders built with Vite, HTML5, CSS3, and Vanilla JavaScript.

## Deploying to Vercel

- **Framework Preset**: Vite
- **Root Directory**: `newsite` (or `./`)
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`

## Local Development

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```
